# Cheatsheet dos Terminais - WezTerm / Kitty / Ghostty
> WezTerm = principal · Kitty = fallback · Ghostty = terceiro fallback.

## WezTerm (padrão + config)

| Ação | Tecla |
|---|---|
| Nova aba | `Ctrl+Shift+T` |
| Fechar aba | `Ctrl+Shift+W` |
| Próxima / Anterior aba | `Ctrl+Tab` / ` Ctrl+Shift+Tab` |
| Ir para aba "N" | `Ctrl+1..9` |
| Split Vertical | `Ctrl+Shift+Enter` |
| Split Horizontal | `Ctrl+Shift+\|` |
| Navegar pelos painéis | `Ctrl+Shift+Setas` |
| Fechar painel | `Ctrl+Alt+W` |
| Copiar / Colar | `Ctrl+Shift+C` / `Ctrl+Shift+V` |
| Buscar no scrollback | `Ctrl+Shift+F` |
| Copy Mode (navegar com teclado) | `Ctrl+Shift+X` |
| QuickSelect (agarrar links/texto) | `Ctrl+Shift+Espaço` |
| Scroll página | `Shift+PageUp/Down` |
| Fonte + / - / reset | `Ctrl+'+'` / `Ctrl+'-'` / `Ctrl+0` |
| Tela Cheia | `Alt+Enter` |
| Recarregar config | `Ctrl+Shift+R` |
| Unicode input | `Ctrl+Shift+U` |

## Kitty (defaults)

| Ação | Tecla |
|---|---|
| Nova aba | `Ctrl+Shift+T` |
| Nova janela (split pelo layout) | `Ctrl+Shift+Enter` |
| Próxima / anterior aba | `Ctrl+Shift+Right/Left` |
| Próxima / anterior janela | `Ctrl+Shift+]` / `Ctrl+Shift+[` |
| Trocar layout | `Ctrl+Shift+L` |
| Fechar aba | `Ctrl+Shift+W` (fecha a janela) |
| Sair do Kitty | `Ctrl+Shift+Q` |
| Copiar / Colar | `Ctrl+Shift+C` / `Ctrl+Shift+V` |
| Colar da seleção | `Ctrl+Shift+S` |
| Busca no scrollback | `Ctrl+Shift+H` (less) |
| Scroll linha / página | `Ctrl+Shift+Up/Down` / `Ctrl+Shift+PageUp/Down` |
| Topo / fim | `Ctrl+Shift+Home/End` |
| Abrir URL (hints) | `Ctrl+Shift+E` |
| Selecionar caminho/linha (hints) | `Ctrl+Shift+P>F` / `P>L` |
| Fonte + / - / reset | `Ctrl+Shift++` / `Ctrl+Shift+-` / `Ctrl+Shift+Backspace` |
| Tela cheia | `Ctrl+Shift+F11` |
| Editar / recarregar config | `Ctrl+Shift+F2` / `Ctrl+Shift+F5` |
| Unicode input | `Ctrl+Shift+U` |

## Ghostty (defaults)

| Ação | Tecla |
|---|---|
| Nova aba | `Ctrl+Shift+T`
| Fechar aba/split | `Ctrl+Shift+W` |
| Próxima / anterior aba | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Nova janela | `Ctrl+ Shift+N` |
| Split à direita | `Ctrl+Shift+0` |
| Split embaixo | `Ctrl+Shift+E` |
| Ir para split (setas) | `Ctrl+Alt+Arrows` |
| Split anterior / próxima | `Super+Ctrl+[` / `Super+Ctrl+]` |
| Ir para a aba 'N' | `Alt+1..9` (Alt+9 = última) |
| Copiar / Colar | `Ctrl+Shift+C` / `Ctrl+Shift+V` |
| Busca | `Ctrl+Shift+F` |
| Selecionar tudo | `Ctrl+Shift+A` |
| Fonte + / - / reset | `Ctrl+'+'` / `Ctrl+'-'` / `Ctrl+0` |
| Tela cheia | `Ctrl+Enter` |
| Zoom do split | `Ctrl+Shift+Enter` |
| Paleta de comandos | `Ctrl+Shift+P` |
| Recarregar config | `Ctrl+Shift+,` ⋅ Abrir config: `Ctrl+,` |
| Inspector | `Ctrl+Shift+I` |
